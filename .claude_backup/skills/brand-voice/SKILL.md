# Skill : Contenu & Brand Voice

## Voix a 3 niveaux

### Niveau Plateforme (Simply)

- **Ton** : Expert, confiant, accessible
- **Pronom** : "Nous" / "Vous"
- **Registre** : Professionnel sans etre corporate creux
- **Posture** : On sait de quoi on parle, on simplifie la vie des clubs

### Niveau SimplyFoot (Football)

- **Ton** : Chaleureux, concret, passion terrain
- **Posture** : On vit le foot amateur, on connait le quotidien des clubs
- **Vocabulaire** : match, entrainement, effectif, vestiaire, terrain, saison, convocation, district, educateur, weekend, dimanche matin
- **Exemple CORRECT** : "Gerez votre club comme un pro, meme le dimanche matin a 9h sur terrain gras."
- **Exemple INTERDIT** : "Optimisez vos process de gestion sportive."

### Niveau SimplyRugby (Rugby)

- **Ton** : Solide, direct, fraternel
- **Posture** : Valeurs collectives, engagement, solidarite
- **Vocabulaire** : melee, touche, essai, pack, avants/arrieres, ecole de rugby, federale, troisieme mi-temps, ovalie
- **Exemple CORRECT** : "Votre club avance en pack. Votre outil de gestion aussi."
- **Exemple INTERDIT** : "Gerez votre equipe de rugby facilement."

### Niveau SimplyHandball (Handball)

- **Ton** : Vif, moderne, energique
- **Posture** : Energie, dynamisme, polyvalence
- **Vocabulaire** : parquet/salle, ailier, pivot, contre-attaque, tir, jet de 7m, plateau, gardien, defense
- **Exemple CORRECT** : "Votre club merite la meme intensite dans sa gestion que sur le parquet."
- **Exemple INTERDIT** : "La solution de gestion pour les clubs de handball."

## Regles de redaction

### Structure type
```
Accroche (emotionnelle/concrete) → Explication (benefice) → Preuve (chiffre/temoignage) → CTA
```

### 7 interdictions de contenu
1. Copier-coller foot → rugby/handball sans adaptation du vocabulaire
2. Ton startup ("disruptif", "game-changer", "revolutionnaire")
3. Lorem ipsum ou texte placeholder
4. Promesses inverifiables ("10 000 clubs" en lancement)
5. "Cliquez" dans un CTA
6. Paragraphes > 4 lignes en landing page
7. Jargon technique non sportif

### Donnees chiffrees credibles

| INTERDIT | CORRECT |
|---|---|
| 10 000 clubs utilisateurs | Deja adopte en Ile-de-France et Occitanie |
| 99% de satisfaction | Note de 4.8/5 par les clubs testeurs |
| Des milliers de matchs geres | Plus de 500 matchs organises cette saison |

| Element | Exemple |

| Placeholders | "ex: AS Saint-Michel" |
| Erreurs | "Cet email semble invalide. Verifiez le format." |
| Succes | "Merci ! Notre equipe vous contacte sous 24h." |
| Boutons | "Envoyer ma demande" |
| Etats vides | "Aucun resultat pour cette recherche." |
| Loading | "Chargement en cours..." |

## Exemples de textes par section

### Hero
```
Titre : [Verbe d'action] + [benefice concret]
Sous-titre : [Pour qui] + [comment ca change leur quotidien]
CTA : [Action] + [benefice]
```

### Feature card
```
Titre : [Benefice] (pas nom de fonctionnalite)
Description : [Situation concrete] + [comment l'outil aide]
```
