# Decisions (ADR)

Journal des decisions architecturales et techniques qui engagent le projet.

## Nomenclature

`NNNN-titre-court.md` avec numerotation sequentielle (0001, 0002, etc.)

## Statuts possibles

- `proposed` — Propose, en discussion
- `accepted` — Valide, en vigueur
- `superseded` — Remplace par un ADR plus recent
- `deprecated` — Abandonne

## Regles

- Toute decision engageant le projet 3+ mois doit etre documentee ici
- Un ADR `accepted` ne se modifie plus — on cree un nouvel ADR qui le `supersedes`
- Les decisions `critical` doivent apparaitre dans `INDEX.md`
