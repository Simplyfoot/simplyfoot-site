# Commande: /context <sujet>

## Usage

Recharge intelligemment le contexte pertinent pour un sujet.

## Mappings

| Argument | Fichiers charges                                      |
| -------- | ----------------------------------------------------- |
| `colors` | `memory/context/design-tokens.md` + ADR couleurs      |
| `i18n`   | `memory/context/routing-map.md` + learnings area:i18n |
| `brand`  | `memory/context/brand-configs.md`                     |
| `stack`  | `memory/context/stack-details.md`                     |
| `3d`     | learnings area:3d + blockers area:3d                  |
| `routes` | `memory/context/routing-map.md`                       |
| `api`    | `memory/context/api-contracts.md`                     |
| `all`    | Tous les fichiers context/                            |

## Procedure

1. Identifier les fichiers lies au sujet (voir INDEX.md)
2. Les charger dans le contexte
3. Confirmer : "Contexte charge : [liste]. Pret pour [sujet]."
